# مونتاج كنان

SwiftUI iOS 17+ app (RTL Arabic, black and gold). Built by GitHub Actions into an ad-hoc signed `.ipa` for sideloading (Sideloadly).

Commands go to Kenan over WhatsApp; live progress is read from `status.json` on the app's site. The in-app «عرض تجريبي» is a prepared demo on bundled clips and does not edit video.
